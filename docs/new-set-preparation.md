# 新セット直後の準備モード

対象はStandard / Pioneer / Modern / Legacy共通。デッキがまだ集まらない発売直後でも、直前環境の採用実績と新セットからの追加準備候補を分けて使えます。

## 試す

「新セット直後の準備モード」をオンにし、「横浜2026・モダンの設定」を押して検索します。大会日2026-10-03、リアリティ・フラクチャー（FRA）、構築適用日2026-09-25を自動設定します。10月4日に使う場合は大会日を変更してください。他のイベントではフォーマットと大会日から候補を提示し、名前で選択できます。セットの種類・発売日・構築適用日・日程の出典を表示します。

候補範囲は大会日前180日〜大会後90日。大会後の候補は選択不可で、大会日前の通常セットをおすすめとして先頭に表示します。Standard/Pioneerでは通常・基本セット、Modernでは統率者製品以外、Legacyでは統率者製品も表示します。これは全収録カードの使用可否の保証ではなく、検索時にカード単位で絞り込みます。公式登録の適用日がなければ発売日を仮置きし、未確認と表示します。手動で日付調整もできます。セット一覧を取得できなければ保存済み一覧・本体履歴を注記付きで使用し、一覧にない場合だけコードを手動指定します。

- 直前環境: 構築適用日の前日と今日の早い方までのデッキ。開始日はその時点の環境イベントから決める。新セット導入後のデッキを過去実績に混ぜない。
- 追加準備候補: 指定セットの紙の全カードをScryfallから取得し、関連トークン・紋章・既知の補助物判定で現物を生成。採用デッキ0件でも表示する。カウンターだけのカードは現物にしない。
- 新環境の実績を見たい時は準備モードをオフにして通常検索する。現段階で両期間のメタ統計を同時に合算しない。

既知の禁止カードはScryfallの取得時点の使用可否で除外します。直前環境の統計は歴史的な参考資料で、当日使用可能なデッキ一覧ではありません。未発売セットでnot_legalのカードは暫定候補として含め、当日の使用可否未確認と明示します。構築適用日を過ぎたセットではnot_legalも除外します。カード情報・関連トークンの未収録、取得失敗、新メカニズムの網羅未確認を表示します。公開途中の一覧を「全件揃った」とは表示しません。

同一現物を両枠で表示しても「抜いた」チェックは同じキーで同期します。追加候補に採用率0%や通常の優先順位評価を表示しません。追加枠の日本語画像の後追い補完は現段階では行わず、辞書の日本語名と取得可能な画像を使用します。

## 日付の根拠

- [横浜公式案内](https://mtg-jp.com/events/detail/0000053/?p=0): 2026-10-03〜04。
- [Reality Fracture公式日程](https://wpn.wizards.com/en/news/reality-fracture-dates-and-details): プレリリース2026-09-25、発売2026-10-02。
- [紙の構築使用開始日についての公式説明](https://magic.wizards.com/en/news/announcements/format-legality-shifts-to-prerelease-with-phyrexia-all-will-be-one): プレリリース開始からの使用。
- [The Hobbit公式プレリリース案内](https://magic.wizards.com/en/news/feature/the-hobbit-prerelease-guide): 2026-08-07開始。

HOB・FRAはセットコード付きの公式適用日で自動発売日イベントを置換します。未確認セットは自動発売日を暫定起点と明記します。全歴史セットの適用日補正・将来ローテーションの完全シミュレーションは行いません。

## 併せて修正した監査事項

1. 構造化デッキで一致しないカードをページ本文から再採用する経路を削除。環境外デッキの本文や記事の言及による混入を防ぐ。
2. 採用デッキ全URLで重複除去し、表示上限を超える発生源間の二重計上を解消。検索上限内の同じデッキ母集団で集計。
3. 関連現物の取得失敗を無言で捨てず警告にする。不正な大会日を拒否。hidden属性のCSS上書きによる誤表示を防ぐ。
4. ローカルサーバーを127.0.0.1へ限定し、別サイトOriginからのPOSTを拒否。
5. 狭い画面でタイトルを潰さない配置に変更。印刷でログが重ならないよう除外し、更新前結果の警告は残す。
