# Melee大会の提出リストで準備する

大会当日に提出リストを受け取れる場合は、環境全体のサンプルより、その大会に出るカードを使って準備します。「この大会のリストで準備」は他大会のデッキを混ぜません。通常検索の20〜600件の上限と新セット準備モードは適用せず、取り込めた大会内の全リストを集計します。

## 操作

1. 「この大会のリストで準備」を選びます。
2. フォーマット、大会日、Meleeの大会URLを指定します。「今回の横浜大会を入力」は大会411350、Modern、2026-10-03、公開ページで確認した537人を入力します。人数は現在の参加者数に修正してください。
3. 大会から受け取ったリストをファイルで選ぶか、英語カード名のデッキテキストを貼り付けます。大会名と参加人数は任意です。
4. 「この大会のリストとして取り込む」を押し、読み込んだ件数と未取得人数を確認します。
5. 「この大会のトークンを探す」を押します。各トークンの採用一覧、または検索済みデッキ一覧からメイン・サイドのカード画像を開けます。

同じ公開サイトの利用者は、同じ大会URLを入力して「大会を読み込む」で保存済みリストを呼び出せます。サーバーのR2に保存するため、取り込み端末とスマホが異なっても呼び出せます。ローカル版の保存はそのPCの`.cache/tournaments/`です。公開版とローカル版の間では同期しません。「抜いた」チェックは従来どおり各ブラウザに保存します。

同じ大会URLへの取り込みは全リストの置き換えです。追記ではありません。カードの表記・枚数が不正なデッキは未取得として表示し、正常なリストを集計します。全ファイルの書式が読めない、正常なデッキがないなどの失敗では保存済みの大会を変更しません。

## 対応形式

最大2000リスト、入力ファイルと貼り付けテキストの合計3MBまで。メイン60〜250枚、サイド15枚以下の構築リストが対象です。リミテッドには対応しません。カード名は英語です。日本語のプレイヤー名・大会名・デッキ名は使用できます。

### Arena／MTGOテキスト

```text
Player: Example Player
Deck Name: Example Deck
URL: https://melee.gg/Decklist/View/00000000-0000-0000-0000-000000000001
Deck
4 Ocelot Pride (MH3) 38
56 Plains

Sideboard
15 Mountain
```

上記は書式の例であり、実際の大会提出リストではありません。`Player:`、`Deck Name:`、`URL:`は任意です。複数リストは各リストの先頭に`Player: 名前`を付けるか、`===`の行で区切ります。MTGO形式のメイン後の空行はサイドボードの開始として扱います。Arena形式のセット・コレクター番号を除き、Companion宣言はサイドボードと二重計上しません。

### CSV／TSV

1カード1行です。`Player`、`DecklistId`、`URL`のいずれかを識別列にします。`CardName`と`Quantity`は必須で、`Board`は`main`または`sideboard`（省略時はメイン）です。`DeckName`とMelee原リストの`URL`は任意です。カンマを含むカード名などは引用符で囲みます。

```csv
Player,DeckName,CardName,Quantity,Board
Example Player,Example Deck,"Tamiyo, Inquisitive Student",4,main
Example Player,Example Deck,Island,56,main
Example Player,Example Deck,Dispel,15,sideboard
```

### JSON

デッキ配列、または`{"decks":[...]}`を指定します。カードは`name`と`count`（`quantity`も可）です。

```json
[
  {
    "player": "Example Player",
    "title": "Example Deck",
    "mainboard": [{"name":"Ocelot Pride","count":4},{"name":"Plains","count":56}],
    "sideboard": [{"name":"Mountain","count":15}]
  }
]
```

これは本ツールが受け付ける書式です。Meleeのスタッフ向け出力・APIの全形式をそのまま受け付けると保証するものではありません。実際の出力形式が異なる場合は変換が必要です。

## 網羅性と取得制限

参加人数を入力した場合だけ、読み込んだ正常なリスト数と比較します。例えば537人に対して25件なら未取得512人分として表示します。参加総数が不明なら「全員分か未確認」です。各トークンの採用率の母数は読み込めたリスト数で、大会の総人数ではありません。同じMeleeデッキURLだけを重複除外し、カード構成が同じ別プレイヤーのリストをまとめません。

大会のカード名をScryfall collection APIで直接照合します。古い候補カードキャッシュに依存しません。照合できないカードは名前と件数を警告し、必要トークンが未完備であることを表示します。提出カードのフォーマット使用可否やデッキの適法性を検証する機能ではありません。

2026-10-03に大会411350の公開ページをブラウザで確認しました。公開順位表は25件ずつのページに分かれ、デッキへのリンクがあります。一方、本ツールの通常のサーバー取得はHTTP 403でした。動的・分割された一覧の先頭ページを全参加者として集計しません。現在、初回の大会URLだけから全リストを自動取得する機能は完成していません。URLからの読み込みは登録済みデータの呼び出しが基本です。

[Melee公式のAPI案内](https://help.melee.gg/docs/api-use/)によるとAPIアクセスは大会運営組織・許可されたスタッフ向けです。公式アクセスを使うには組織の承認とMeleeからの認証情報が必要です。現在はその認証情報を持たず、ファイル／コピーによる取り込みを使用します。ログイン用Cookieや非公開エンドポイントを使用しません。
