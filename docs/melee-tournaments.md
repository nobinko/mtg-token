# Meleeの最近の大会から直接取得して準備する

「大会を選ぶ」はMeleeの最近の大会を探し、選んだ大会の公開デッキリストを直接取得します。保存済み大会がなくても使えます。通常検索の20〜600件の上限と新セット準備モードは適用せず、その大会で取得できた全リストを集計します。

## 操作

1. 最初に開く「大会を選ぶ」でフォーマットを選びます。Meleeから終了した最近の大会と会場情報を取得します。初回は少し時間がかかります。
2. 「国内」が最初に表示されます。開催日の新しい順に日付・人数・会場付きカードで並び、「大会を絞る・一覧を更新」から大会名・地域・参加人数で絞り込めます。小規模大会にも人数の下限はありません。海外・オンライン・所在地未確認の大会は「その他」から選びます。
3. 一覧から大会を選ぶと、その大会の公開リストを直接取得します。ファイルやMeleeログインは不要です。大会日とフォーマットは大会に合わせます。大きな大会では数分かかる場合があります。
4. 取得後は選んだ大会と確認人数を表示します。直下の「準備表を作る」を押します。大会を変える場合は「選び直す」、取得リストや日時を確認する場合は「取得したリスト・詳細を見る」を開きます。未取得分の警告は折りたたまず表示します。各トークンの採用一覧や検索済みデッキ一覧からカード画像を開けます。

初期の期間は最近90日です。30日・180日・1年へ変更できます。一度にMeleeの直近200大会を確認し、期間内の大会を表示します。カードは最初の6大会を表示し、「もっと大会を見る」で6大会ずつ展開します。「さらに前の大会を探す」で続きの200大会を追加できます（全体2000大会まで）。国内大会すべての網羅を保証する一覧ではなく、取得範囲と取得日時は絞り込みの中に表示します。公開一覧・会場情報は15分間再利用し、「一覧を更新」で大会一覧を更新します。URLが分かる場合は「ほかの方法でリストを使う」→「大会URLから取得」も使えます。

国内判定は会場の国と住所で行い、大会名の日本語やJapanという文字だけでは判定しません。Meleeに会場がない場合は、正確な開催日とリンク先を照合できる確認済みの主催者資料を補助に使います。例えば[2026-08-08の主催者開催案内](https://note.com/massan_gabagaba/n/n24918c646d37)には、東京の東陽区民館でのスタンダード・レガシー・モダン大会が記載されています。未確認の会場を国内へ自動分類しません。

### 非公開リストを本人のAPI認証で取得する

「ほかの方法でリストを使う」で大会URLを指定して「API利用承認済みの方のみ（実接続未確認）」を開き、**本人のAPI用IDとシークレット**を入力します。スタッフ追加の案内だけを受け取った場合は、この欄への入力は不要です。スタッフ画面からの公式JSON書き出しは、下の手順で使えます。認証情報はそのリクエストだけに使用し、入力欄は処理後に消去します。ブラウザ保存領域・環境変数・共有サーバーの保存先・ログへ認証情報を保存せず、他の利用者へ流用しません。Googleのパスワードを入力する欄ではありません。

[Melee公式案内](https://help.melee.gg/docs/api-use/)では、主催組織の許可と指定スタッフ資格に加え、API利用承認後にclient ID・secretを発行すると説明しています。[API仕様書](https://melee.gg/swagger)はユーザー単位のBasic認証です。本ツールは`/api/tournament/{id}`とページ送りした`/api/decklist/list/{id}`を呼び出し、認証・権限不足や未対応の応答形式を明示します。**有効な本人のAPI認証情報での接続試験は未実施**です。公開リストの直接取得とは検証状態を区別してください。公式サイトのログインCookieは使用しません。

### Meleeのスタッフ権限がある場合

APIキーを入力せず、Meleeの公式書き出しから取り込めます。

1. 「ほかの方法でリストを使う」で大会URLを入力し、「Meleeのスタッフ画面を開く」を押します。Meleeへのログインを求められたら、スタッフに追加された自分のアカウントでログインします。
2. Meleeの「デッキリスト」タブで「エクスポート」→「JSONとしてダウンロード」を選びます。
3. 本ツールに戻り、保存したJSONファイルを選んで「この大会のリストとして取り込む」を押します。

公式JSONの`Records`から英語カード名と枚数を読み取り、メイン（区分0）、サイド（区分99）、相棒（区分4）を集計します。相棒はサイド枚数に含めます。大会ID・ゲーム・フォーマットが画面の指定と異なるファイルは取り込みません。未知のカード区分や不完全なリストは未取得として表示します。元のJSONはそのまま残し、本ツールの保存データには公開用の表示名・デッキ名・原リストURL・カード構成だけを使います。アカウント名、スタッフ用の名前、Discord名、内部のプレイヤーIDなどは保存しません。

2026-10-16に大会411350のスタッフ画面で公式JSONを実際に書き出し、536件とカード構成を確認しました。書き出せた件数だけで「参加者全員分」とは判定しません。参加総数を別途確認して入力してください。

大会リストは取り込んだ端末・ブラウザのIndexedDBに保存します。公開版でもローカル版でも、他の利用者が同じ大会URLを知っているだけでは読み出せません。別の端末・ブラウザ・公開先との間では同期しません。共用PCでは自分のブラウザプロファイルを使ってください。ブラウザの保存データを消した場合や別の端末では、元のファイルを取り込み直します。旧バージョンでサーバーに共有保存した大会は自動移行・自動公開しません。

Meleeの通常ログインとAPI認証は別の入口です。公開リストは認証なしで取得し、スタッフ用APIは入力した本人の認証情報だけで取得します。トークン検索時は選んだ大会のリストを処理サーバーへ送って再検証し、カード名だけをScryfallへ照合します。提出リストのサーバー共有保存と、共有ログへの大会検索ログの配信は行いません。「抜いた」チェックも各ブラウザに保存します。

同じ大会URLへの取り込みは自分の保存分の全リストを置き換えます。追記ではありません。カードの表記・枚数が不正なデッキは未取得として表示し、正常なリストを集計します。全ファイルの書式が読めない、正常なデッキがないなどの失敗では保存済みの大会を変更しません。人数の下限はなく、少人数の店舗・草の根大会でも使えます。

## 対応形式

最大2000リスト、入力ファイルと貼り付けテキストの合計3MBまで。メイン60〜250枚、サイド15枚以下の構築リストが対象です。リミテッドには対応しません。カード名は英語です。日本語のプレイヤー名・大会名・デッキ名は使用できます。

### Arena／MTGOテキスト

```text
Player: Example Player
Deck Name: Example Deck
URL: https://melee.gg/Decklist/View/00000000-0000-0000-0000-000000000001
Deck
4 Ocelot Pride (MH3) 38
56 Plains

Sideboard
15 Mountain
```

上記は書式の例であり、実際の大会提出リストではありません。`Player:`、`Deck Name:`、`URL:`は任意です。複数リストは各リストの先頭に`Player: 名前`を付けるか、`===`の行で区切ります。MTGO形式のメイン後の空行はサイドボードの開始として扱います。Arena形式のセット・コレクター番号を除き、Companion宣言はサイドボードと二重計上しません。

### CSV／TSV

1カード1行です。`Player`、`DecklistId`、`URL`のいずれかを識別列にします。`CardName`と`Quantity`は必須で、`Board`は`main`または`sideboard`（省略時はメイン）です。`DeckName`とMelee原リストの`URL`は任意です。カンマを含むカード名などは引用符で囲みます。

```csv
Player,DeckName,CardName,Quantity,Board
Example Player,Example Deck,"Tamiyo, Inquisitive Student",4,main
Example Player,Example Deck,Island,56,main
Example Player,Example Deck,Dispel,15,sideboard
```

### JSON

デッキ配列、または`{"decks":[...]}`を指定します。カードは`name`と`count`（`quantity`も可）です。

```json
[
  {
    "player": "Example Player",
    "title": "Example Deck",
    "mainboard": [{"name":"Ocelot Pride","count":4},{"name":"Plains","count":56}],
    "sideboard": [{"name":"Mountain","count":15}]
  }
]
```

上記の本ツール用JSONに加え、スタッフ画面の「JSONとしてダウンロード」で保存したMelee公式JSON配列にも対応します。Meleeの表形式CSVやAPIの全形式に対応するものではありません。

## 網羅性と取得制限

直接取得では公開順位表を100件ずつ最後まで読み、途中でドロップした参加者も含めるため最初のラウンドから確認します。カード本文は同時4件まで取得します。先頭ページだけを全員分として扱いません。現在の登録数と順位表の人数が異なる場合は両方を表示し、大きい方を確認人数にします。例えば2026-10-16の大会411350では、現在登録536人に対し公開順位表と公開リストは537件でした。

ファイル取り込みでは、参加人数を入力した場合だけ正常なリスト数と比較します。参加総数が不明なら「全員分か未確認」です。各トークンの採用率の母数は取得できたリスト数で、大会の総人数ではありません。同じMeleeデッキURLだけを重複除外し、カード構成が同じ別プレイヤーのリストをまとめません。

大会のカード名をScryfall collection APIで直接照合します。古い候補カードキャッシュに依存しません。照合できないカードは名前と件数を警告し、必要トークンが未完備であることを表示します。提出カードのフォーマット使用可否やデッキの適法性を検証する機能ではありません。

公開取得はMelee公式の公開画面が使用する検索・順位表・デッキ詳細を読み取ります。サイトの変更やHTTP 403・429は明示し、アクセス拒否を回避したり、取得失敗を空の完全取得として扱ったりしません。HTTP通信は本ツール名を明記した標準形式のUser-Agentを使用します。

通信の途中切断・25秒の応答待ちタイムアウト・HTTP 408/500/502/503/504では、失敗した読み取りだけを750ms、2秒の間隔で最大2回再試行します。大会全体を最初から取り直すことはありません。HTTP 401/403/404/429、リダイレクト、証明書エラーは再試行しません。本文受信中の切断も同じ扱いです。回復できないリストは未取得として残し、全件取得済みにはしません。失敗の原文・レスポンス本文・認証情報は利用者向けのエラーに含めません。

## 新規取得の通し確認（2026-10-18）

ローカルサーバーを再起動し、ブラウザーで「最近の国内大会」から2026-10-03のチャンピオンズカップファイナルを選択。保存済みの読み込みを使わず、Melee公開リスト537件を22:06:20（日本時間）に新規取得した。現在登録536人・公開順位表537人というMelee側の差は画面に併記する。

そのまま「準備表を作る」まで操作し、提出リスト537件、発生源175種類、現物候補115件、同じ仕様をまとめた準備対象88種類、カード名の未照合0件を確認。都市の承認・昼夜・計画・ワープ等の補助物も含む。「別途用意するもの」の1種類はストーム・カウントで、対象セット版が見つからなかったための表示であり、デッキの取得漏れではない。照合の詳細では、環境巡回用の「新規取得0件」を表示せず、リストの取得元・取得日時・未照合数を表示する。

前回の通信失敗そのものはこの確認では再現しなかった。途中切断・タイムアウト・503・応答本文の切断をテストで再現し、成功時の全件保持、再試行上限、失敗したキャッシュの再取得、認証と制限の非再試行を確認した。全399テストとビルドが成功。画面証跡はローカルの `.cache/melee-live-20261018/` に保存する。

## 他フォーマットの新規取得確認（2026-10-19）

ブラウザーのフォーマット選択から大会一覧を読み、保存済み大会の読み込みを使わずに公開リストを新規取得。そのまま準備表を作成し、日本語補完の完了とカード名の未照合数まで確認した。Modernの前日確認に加え、現在対応する残り3フォーマットが対象。

StandardとLegacyは国内会場の確認された大会から選択。Pioneerは90日・180日・365日へ期間を広げたが、今回の検索では国内会場を確認できた大会がなく、「その他」の所在地未確認大会を使用した。国内のPioneer大会を通した実績とは扱わない。

- Standard: 計画・出来事・準備済み状態・クラス・事件・部屋・消尽・変装と、ラルの紋章／ストーム補助などを表示。
- Legacy: 地下街と部屋の宝物／スケルトン、通常ダンジョン3種とそのトークン、統治者・昼夜・刻印・待機・ワープなどを表示。統率者、バルダーズ・ゲート、指輪物語、モダンホライゾンのセットも抜き出し先に含む。
- Pioneer: 計画・昼夜・速度・毒カウンター・出来事・ワープ・暗号・部屋などを表示。

StandardとLegacyの「別途用意」1種類はストーム・カウント。準備対象セット版が見つからない状態と、印刷情報の取得・照合未完了を区別し、前者は対象名を添えた案内、後者は警告として表示する。Pioneerの別途用意は0種類。

取得制限も実画面で確認した。[Fortnightly Proxy Pioneer](https://melee.gg/Tournament/View/476867)では公開リスト1/4人分・未取得3人分を表示。[第314回フライデーアシムマジック](https://melee.gg/Tournament/View/485939)ではリスト非公開として停止し、完全取得や空の準備表に置き換えなかった。

国内大会がない場合に「最近180日／1年まで広げる」「その他の大会を見る」を追加。200大会ごとの検索途中と、2000大会の検索上限の案内を分離した。セット案内は選んだフォーマットに合わせ、同じ仕様なら古い印刷を準備に使えることを明示する。大会リストの適法性を判定する機能ではない。

最終版で既存399テスト、ビルド、差分検査が成功。3フォーマットの検証タブにブラウザーの警告・エラーログはなかった。画面・一覧応答・検査ログはローカルの `.cache/multiformat-20261019/` に保存。これは各フォーマットの公開大会から準備表までの確認であり、全カード・全大会の網羅性や、ひとり回しの全ルール自動化を保証する検証ではない。
