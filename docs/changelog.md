## 2026-07-17

- 環境イベント表に Marvel Super Heroes 発売（2026-06-26、standard/pioneer/modern/legacy）と禁止改定（2026-06-29、Legacy: Candelabra of Tawnos 禁止、次回改定 2026-08-10）を追記。
- MTGO の大会名（Challenge 64 / League 等）がアーキタイプ名として表示される問題を修正。イベント語彙・日付をタイトル推定のノイズ扱いにし、MTGO デッキのタイトル由来フォールバックを Unknown に固定して土地色フォールバックへ委ねるようにした。
- 現物の採用デッキ数が表示用デッキ一覧の切り詰め（36件）で頭打ちになるバグを修正。集計を一意デッキURL＋切り詰めあふれ分の加算に分離し、回帰テストを追加。
- 大会日の初期値を、HTMLに固定していた過去の日付から「直近の週末（土日ならその日、平日なら次の土曜日）」の自動設定に変更。
- app.js / styles.css 変更時に index.html の `?v=` バージョン文字列を更新する規約を architecture.md に明記。
- 巡回元インデックスページのキャッシュに6時間の鮮度上限を導入。翌日以降の検索で新しいデッキが静かに漏れないようにした（個別デッキページは従来どおり無期限、取得失敗時の期限切れ代替も維持）。
- 日本語画像・カード名の後追い補完を分割送信にし、現物160種/発生源120枚を超える検索でも全件補完されるようにした。進行状況もステータスに表示。
- Scryfall候補クエリに変異（Morph / Megamorph）を追加し、クエリ変更時に古い候補キャッシュを使わないよう版数管理を導入。
- 2025-11以降のセットの新メカニズムを監査し、除外ゾーン追跡が必要な Airbend（TLA）と Paradigm（SOS）を候補クエリと現物候補（カード・マーカー）に追加。カウンター管理のみの Blight / Plan / Power-Up 等は従来方針どおり対象外。
- magic.gg の deck-list で「Standard Brawl」等の Brawl 系が構築フォーマット検索に混ざらないようにし、`<` 小文字エスケープの取りこぼしも修正。
- mtgo.com の重い個別ページ向けにページ取得タイムアウトを15秒から25秒に延長。
- Start Your Engines 補助の生成条件を他の補助と同じ個別判定にし、トークンも出すSYEカードで補助が漏れないようにした。
- トークン頻度表の描画を innerHTML から DOM 構築に変更。
- セット発売・禁止改定ごとに確認する鮮度依存データ（環境イベント表、候補クエリ、アーキタイプ辞書、和名・ランド表）の定期メンテ手順を architecture.md に明記。

## 2026-06-02

### 監査対応

- 検出した生成カードを現物化する前の上限を100件から600件に引き上げ。
- ログパネルを初期表示で展開し、検索開始直後から巡回ログを見えるように調整。
- 検索ID付きログ配信に変更し、画面では現在の検索ログだけを表示。古い検索ログや別タブのログは混ぜない。
- フォーマット不一致の `<deck-list>` を全文フォールバックで拾い直さないよう修正。
- Scryfall検索系APIの呼び出し間隔を500ms以上にし、Scryfall由来キャッシュを24時間保持に変更。
- 非公式Fan Content表記と、アクセス制限を回避しない運用方針をREADME/利用手順/画面に追加。
- カード画像の表示を `contain` にして、著作権表記やアーティスト名を切り落としにくくした。
- Node.js標準テストを追加し、デッキ抽出、リンクフィルタ、検索集計、コピー判定、検出上限を検証。

### ドキュメント体系の整理

- READMEを入口専用に短縮。
- 利用手順を [usage.md](usage.md) に分離。
- 設計思想、データフロー、巡回方針、環境判定、アーキタイプ推定、現物候補判定、モジュール責務を [architecture.md](architecture.md) に分離。
- デッキリスト取得元の実測根拠を [decklist-sources.md](decklist-sources.md) に分離。

### 入力防御と検索ボタン制御

- 検索中に無効化するボタンが画像言語ENボタンになっていたため、検索ボタンを直接参照するよう修正。
- API直叩き時の `maxChildPages` を20-600件に正規化し、不正値は既定値300件に戻すよう修正。

### デッキリストソース実測

- 晴れる屋メタページは取得できるが、検索結果 `result` はAWS WAF challengeで本文0バイトになることを確認。
- 晴れる屋個別 `show` は取得できる例があるが、現行パーサではカード名を抽出できないことを確認。
- MTGO公式は `window.MTGO.decklists.data` JSONからカード名を抽出できることを確認。
- MTGTop8はフォーマットページからイベント/個別デッキへ進み、カード名とイベント日を抽出できることを確認。
- MTGGoldfish個別デッキとMTGDecksはCloudflare 403を確認。

### フォーマット横断の巡回元を再設計

- MTGO公式をデフォルト巡回元に復帰。
- `/decklists` から `/decklist/{format}-...` 形式のリンクだけを辿り、ページ内JSONからリーグ/チャレンジ両方のカード名・公開日を抽出。
- Standard / Pioneer / Modern / Legacy のフォーマット定義を使い、`modern` が `premodern` に誤一致しないようURLセグメントで判定。
- 晴れる屋のメタページはアーキタイプ補助として読むが、AWS WAFで止まる `result` ページは自動巡回しない。
- MTGDecksとMTGGoldfishは完全デッキリストのデフォルト取得元から外す。
- 2026-06-02時点のLegacy環境開始日を2026-05-18として、現環境内デッキはMTGO公式32件 + MTGTop8 171件 = 203件まで取得。299件に届かない場合はソース枯渇として表示する。

### コピー判定とエラー出力

- コピー・マーカーの検出を、盤面に置く現物が必要な表現に限定。
- `Emeritus of Truce // Swords to Plowshares` のように「呪文のコピー」を注釈文で参照するだけのカードをコピー・トークン候補にしないよう修正。
- サーバー例外時に空オブジェクトではなくスタックまたはメッセージをログに出すよう改善。
