# 配布後の環境データ更新

## 利用者の操作

この機能を含む配布版を一度入手すれば、以降の対応形式内の禁止改定・ローテーション履歴は「環境データを更新」で取得できます。Gitは不要です。機能追加前のZIPにはボタンがないため、初回のみ本体の入れ替えが必要です。

フォーマットを選んでボタンを押すと、配布元の環境履歴全体、Scryfallのセット情報、選択フォーマットの候補カードを再取得します。途中の改定を飛ばして長期間使わなかった場合も、履歴全体を読み込みます。全取得と検証に成功した時だけ保存を切り替え、再起動なしで次の検索から利用します。他のフォーマットは検索時に候補を再取得します。

更新後の検索では巡回ページも再取得します。表示済みの結果は更新前であることを表示し、再検索を促します。「抜いた」チェックはブラウザの既存保存を保持します。

最終取得日時は通信が成功した時刻です。公式の最新情報を網羅した保証ではありません。確認範囲・適用日未確認の改定を併記します。通信・互換性・取得内容の異常時は前回の正常な環境データを保持します。

## 配信契約 v1

固定配信先: `https://raw.githubusercontent.com/nobinko/mtg-token/main/data/environment-events.json`

`schemaVersion: 1`、`minimumReaderVersion: 1`、`events`を持つJSONを配信します。`verifiedThrough`は運営が公式情報の網羅確認を終えた日だけ設定し、不明ならnullです。データ内容のSHA-256先頭12桁を表示用の版とします。ハッシュは認証署名ではありません。HTTPSの固定配信元を信頼境界にします。

イベントには`date`、`type`、`title`、`sourceUrl`、`formatsAffected`を持たせます。公式の発表日を`announcedAt`、紙の適用日を`effectiveDate`に保存します。旧手書きイベントの`date`は互換用の適用日です。`autoDetected: true`のイベントは`confirmed: true`と検証済み`effectiveDate`が必要です。検知日を適用日に昇格させません。未確認イベントの影響フォーマットは検知日以降の検索を停止して確認待ちを示します。

利用者側は`.cache/environment/active.json`に履歴・セットイベント・候補カードをまとめて保存し、一時ファイルからrenameで切り替えます。メモリも保存成功後に切り替えます。巡回キャッシュ削除ではこの保存を消しません。候補カードとセット情報は更新後24時間利用し、その後の検索は再取得経路へ戻ります。検索と更新の競合はAPI側で409にします。

`GET /api/environment/status`で状態取得、`POST /api/environment/update`に`{"format":"standard"}`等を送信します。更新先URLを入力から指定することはできません。更新の外部Originは拒否します。

## 運営側の手順

1. 日次CIは差分を未確認イベントとして記録する。公式本文で対象カード・発表日・紙の適用日・変更なしフォーマット・次回予定日を照合する。確認済みイベントに`confirmed: true`と`effectiveDate`を設定する。
2. `npm test`と構文・差分チェック後、公開承認を得て同じ配信先のmainに反映する。利用者が更新ボタンで受信する。
3. 新メカニズムは引き続き判定ロジックの監査が必要。本段階では現物判定コードの遠隔更新は行わない。新しい読み取り機能が必要ならminimumReaderVersionを上げ、本体更新を案内する。

ローカル実装だけでは配信先は更新されません。本変更のmain公開後に実配信先からの更新成功を確認する必要があります。

## 検証と制約

`test/updates.test.js`は、旧同梱状態から複数改定の履歴取得、発表日と適用日の区別、再起動後の復元、途中失敗時の保持、不正形式・非互換・空データの拒否、同時更新を検証します。

`node scripts/verify-update-ui.mjs`は5188番で実際の画面とAPIを起動し、外部取得だけを検証用データに置き換えます。データとキャッシュは一時ディレクトリに隔離し、Ctrl+Cで削除します。実在の改定ではないことをイベント名に明示しています。2026-09-07の画面確認では、更新成功→Modernの環境開始日が検証用適用日へ変化→もう一度更新すると更新前結果の案内、まで確認しました。外部巡回はこの検証では禁止しているため検索デッキは0件です。実際の配信先では未公開形式の拒否とボタン復帰を確認しました。

候補カードはScryfall取得時点の使用可否です。過去大会の完全再現や将来の使用可否は保証せず、検索結果にこの制約を表示します。セット発売のフォーマット分類は既存方式を継続します。新ルールのデータ化と本体自動更新は次段階です。

2026-08-10改定は2026-09-07に[公式発表](https://magic.wizards.com/en/news/announcements/banned-and-restricted-august-10-2026)で対象カード、同日適用、次回2026-10-12を確認しました。全期間の網羅確認は未実施なのでverifiedThroughはnullです。
