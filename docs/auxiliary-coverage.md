# トークン・状態補助物の点検記録

確認日: 2026-10-17。対象は紙のStandard / Pioneer / Modern / Legacyのリストから必要な現物を準備する用途。発生源の使用可否は検索時のカード情報で判定する。

## 表示対象

| 分類 | 対象 | 表示方法 |
| --- | --- | --- |
| 生成物 | クリーチャー・アーティファクト等のトークン、紋章、コピー | 発生源の関連カードを照合。物理コピーは汎用コピーも候補にする |
| プレイヤーの状態 | 昇殿／都市の承認、物語り／不朽の物語、統治者、指輪の誘惑、エンジン始動／速度 | 実物の補助カードと、記録する内容を表示 |
| 探索 | 通常のダンジョン3種、イニシアチブ／地下街 | ダンジョンと、その部屋から生成するトークンも表示 |
| 全体の状態 | 昼／夜 | 両面の補助カードを表示 |
| プレイヤーのカウンター | エネルギー、毒、経験、放射能 | 実物の補助カード。数字はダイス等で管理可能と説明 |
| 追放中のカード | 計画、予顕、出来事、ワープ、待機、反復、秘匿、刻印、暗号、憑依、エアベンド、パラダイム、覇権 | 計画・予顕・出来事は実物を照合。他は用途を説明した汎用マーカー |
| 裏向き | 予示／戦慄予示、変異／大変異、偽装、変装 | 予示・変異の実物も取得。護法の有無と表向きにする方法を区別 |
| パーマネントの状態 | 準備済み、督励、消尽の起動済み、怪物的、高名、容疑、事件の解明、使嗾、留置、結魂、部屋の開放、クラスのレベル、蘇生・疾駆・奇襲、フェイズ・アウト | 状態・期限・対応関係を説明した汎用マーカー |
| 回数の記録 | ストーム、墓地ストーム | 呪文回数と墓地へ置かれた数を別々に表示 |
| 条件付きの補助 | 相棒として公開する場合、両面／合体カードの差し替えが必要な場合 | 用途が必要な場合だけ用意する項目として表示 |

実物のある補助カードも、専用カードの購入を必須とする意味ではない。対象製品の印刷がない場合は「別途用意するもの」、取得に失敗した場合は警告と汎用補助を残す。相棒の古い印刷には現在と異なる説明があるため、現行の{3}で手札へ加える手順を説明に添える。

## 漏れ・誤表示を防ぐ処理

- `lib/auxiliary.js` で検索語・検出条件・日本語名・用途・実物の参照を共通化。長い候補検索は小さい検索へ分け、Oracle IDで和集合を取る。候補キャッシュは版7へ更新する。
- 関連情報の `Card` や `Creature` 型も、既知の補助物だけを取得する。一般のコンボ相手や広告・ミニゲームを混ぜない。関連情報が欠けた補助物は既知の印刷IDから照合する。
- 関連カード一覧には逆向きのリンクもある。ダンジョンの直接のトークン以外へ無差別に再帰しない。毒補助カードから毒を持つ全トークンを拾うような誤りを防ぐ。
- 通常の探索はAFRの3種類を選択肢として用意する。地下街はイニシアチブ／地下街探索から追加する。イベント用のBaldur's Gate Wildernessは通常の探索へ含めない。
- 地下街の通常印刷は反転色フレームでも対象。一般の特殊フレームやプロモを許可する例外には広げない。
- 専用カードと同じ用途の汎用マーカーを二重に数えない。補助物の準備記録は用途で共有し、従来の昼夜・計画等のチェックを引き継ぐ。色・P/T・能力の違うトークンは従来どおり別仕様として扱う。
- 注釈文のないトークン生成キーワードも候補に含める。パーマネント呪文のコピーは戦場でトークンになるため対象にし、インスタント／ソーサリーのコピーだけでは現物を要求しない。

## 数え方と限界

「必要な種類」は実際の各ゲームで全部使うという意味ではなく、対象リストから生じ得る準備候補。ダンジョンの選択肢や相棒・差し替えカードには条件がある。

通常の+1/+1・時間・忠誠・麻痺等の数値カウンターは個別のカード項目にしない。ただし、プレイヤーの資源を区別する公式補助カードや、カウンターがなくなっても続く怪物的・高名等の状態は対象にする。前兆は解決後にライブラリーへ戻るため、追放中の補助は追加しない。

パンチアウト全般、広告、ミニゲーム、イベント専用ダンジョンは名前だけで追加しない。一時的な修整すべてを自動でマーカー化する機能や、対戦中のルールを自動処理する機能ではない。未取得リスト・未収録の関連トークン・将来追加されるメカニズムまで網羅済みとは扱わない。新メカニズムはこの一覧と回帰テストを更新して対応する。

## 検証結果

- 51項目の補助物ルール（うち実物の参照22項目）を共通一覧へ登録。既存テストと回帰テストは203件成功、ビルドと差分検査も成功。
- 公開APIで18発生源の現物を照合。通常ダンジョン3種からの宝物・スケルトン・ゴブリン・アトロパル、地下街の宝物・スケルトン、別セット版の選択を確認。
- 最終版のModern候補は版7・4,977枚。追加した蘇生・疾駆・奇襲・フェイズ・アウト・覇権はそれぞれ実カードでも候補と検出結果を確認。
- 再起動したローカルアプリの検証用リストで、Modern 23項目／Legacy 6項目の準備候補を確認。補助物の採用デッキ数、警告なし、日本語の後追い補完も確認。検証用リストは大会実績ではない。
- ブラウザーは前回の接続エラー画面が残り、操作のアクセス制限があるため、今回の最終表示の目視確認は未完了。APIの確認を画面確認として扱わない。
