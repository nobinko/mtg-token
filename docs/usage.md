# 使い方

MTG Token Finder は、配信卓や大会準備で「どのトークン現物をバルクから抜くか」を決めるためのWebツールです。

## スマホ・PCから公開版を使う

1. [MTG Token Finder](https://mtg-token-finder-nobinko.nobinko.chatgpt.site) を開きます。
2. 管理者から共有されたパスワードを入力します。
3. 以下の基本操作で検索・準備します。スマホではカード画像をタップして拡大できます。

ログインは7日間有効です。「ログアウト」で終了できます。パスワードが変更された場合は、更新されたパスワードでログインし直してください。利用者側のNode.jsインストールやローカルサーバーの起動は不要です。

「抜いた」チェックとひとり回しの保存は、その端末・ブラウザに記録します。PCとスマホの間では自動同期しません。検索キャッシュと環境データは公開サーバーで保存します。

公開版の本体はGitHubの`main`を1時間ごとに確認して更新します。運営向けの手順は[自動公開とパスワード変更](github-deployment.md)を参照してください。

## ローカル版の初回起動

### 1. Node.js をインストールする

https://nodejs.org/ja/ を開き、「LTS」と書かれたボタンでインストーラをダウンロードして実行してください。途中の選択肢はデフォルトのままで構いません。

### 2. `start.bat` をダブルクリックする

リポジトリのフォルダにある **`start.bat`** をダブルクリックします。

- 黒いウィンドウが開き、サーバが起動します。
- 初回だけパッケージをインストールします。
- 数秒後にブラウザが自動で開きます。
- すでに起動中にもう一度ダブルクリックした場合は、エラーにせず既存の画面を開きます。

ブラウザが開かない場合は、手動で次を開きます。

```text
http://localhost:5177
```

### 3. 終了する

黒いウィンドウを閉じてください。サーバも停止します。

## PowerShellで起動する

```powershell
npm install
npm start
```

2回目以降は `npm start` だけで起動できます。停止するときは、サーバを起動したPowerShellで `Ctrl+C` を押します。

## 基本の使い方

最初は「大会を選ぶ」が開きます。フォーマットを選び、日付・会場・人数を見て国内大会のカードを押してください。Meleeから公開リストを取得したら、直下の「準備表を作る」を押します。初回もファイルの準備やMeleeログインは不要です。大会内のカードだけで集計し、取得件数と未取得人数を表示します。[大会選択と取得の詳しい手順](melee-tournaments.md)も参照してください。環境全体を検索する場合は「最近の環境から」に切り替えます。

大会URL・保存済み・スタッフ・APIを使う場合は「ほかの方法でリストを使う」を開きます。Meleeのスタッフ権限がある場合は、「Melee公式へログイン・担当大会を確認」から自分のアカウントでログインします。大会URLを入力して「Meleeのスタッフ画面を開く」→「デッキリスト」→「エクスポート」→「JSONとしてダウンロード」で保存したファイルを、そのまま取り込めます。この方法ではAPIキーを設定しません。

小規模・草の根大会も参加人数で絞り込めます。海外・オンライン・所在地未確認は「その他」へ分かれます。スタッフ追加の案内だけを受け取った方は、自分のMeleeアカウントで公式画面からJSONを書き出して取り込めます。別途API用ID・シークレットを受領した方には「API利用承認済みの方のみ（実接続未確認）」の入口もあります。保存済み大会とファイル取り込みは補助の入口です。取得したリストは自分の端末・ブラウザに保存し、別の人や別端末とは同期しません。

新セット発売直後の大会では「最近の環境から」→「検索設定・取得元を変更」→「取得元・新セット直後の追加準備」を開き、[準備モード](new-set-preparation.md)を使用できます。「横浜2026・モダンの設定」で今回の大会条件を入力できます。

1. フォーマットを選びます。
2. 大会日を指定します。初期値は直近の週末です（今日が土日ならその日、平日なら次の土曜日）。別の大会日ならここで変更します。
3. 検索デッキ数を調整したい場合は「検索設定・取得元を変更」を開きます。
4. 「準備表を作る」を押します。
5. 必要・未準備・準備済みの種類数を確認します。「抜き出すセット」を押してそのセットの準備表へ移動し、手元から抜いたものはカード画像の下の「抜いた」を押してチェックします。
6. 「別途用意するもの」と汎用補助カードの欄も確認し、用意したらチェックします。必要なら「準備表を印刷」を使います。

細かい採用ライン・キャッシュ・データ更新は「検索設定・取得元を変更」にあります。表示順、画像言語、印刷は検索後の「表示・印刷」を開いて変更します。未準備フィルターとセット一覧への移動は常に操作バーに表示します。検索範囲・照合の詳細、採用デッキ・環境内訳、モダン年表、ログは折りたたんで必要なときに開きます。未取得件数や照合の警告は準備表の上にも表示します。

準備の進み具合と操作バーは、下へスクロールしても画面上部に残ります。PCの広い画面では「抜き出すセット」を準備表の右側に固定表示し、セットごとの残り種類数を見ながら移動できます。スマホでは操作バーが2段に収まり、横スクロールせず「未準備だけ」「セット一覧」「表示・印刷」を使えます。

画面右上の太陽／月のボタンで、暗い表示（既定）と明るい表示を切り替えられます。選んだ表示はその端末・ブラウザに記録します。印刷はどちらの表示でも白地の準備表になります。

巡回元URL欄は手動編集できます。イベント固有のURLや、デフォルト巡回元に入れていないサイトの個別URLを試す場合は、1行に1URLずつ追加します。

## トークンから画像付きデッキリストを開く

1. 検索結果のトークンで「このトークンを使うデッキ（画像付き）」を開きます。
2. 大会日・プレイヤー・発生源カードを確認して、デッキを選びます。
3. その実在リストのメイン・サイドを枚数付きカード画像で確認できます。日英の切替、画像の拡大、原リストへの移動に対応します。

採用デッキは検索で取得した全件から照合します。発生源の小画像や表示用の短い採用一覧だけに限定しません。「検索デッキ/リスト」の一覧からも画像付きで開けます。

## トップメタ10と典型デッキ

検索後の「トップメタ10」は、MTGTop8が現在公開している直近2週間の集計です。母数、取得日時、同率時の並び方を見出しに表示します。検索用に集めたデッキの自動分類は別の参考欄であり、この順位には使いません。

1. アーキタイプ行の「典型リストを見る」を押します。
2. 通常は指定大会日と今日の早い方まで、準備モードでは画面に表示された「新セット導入前の実績期間」から、完全リストを最大8件取得します。
3. 取得できたリスト同士を枚数構成で比較し、平均との差が最小の実在リストを典型例として表示します。
4. プレイヤー、大会、順位、日付、原リスト、メイン/サイドの枚数を確認できます。「Arena形式をコピー」でインポート用テキストをコピーできます。

トップメタ自体は現在のスナップショットであり、過去の大会日当時の順位を再現する機能ではありません。大会日が未来の場合や新セット準備モードでは、まだ存在しない大会後の実績を探さず、現時点または新セット導入前の実在リストを準備用ベースラインとして表示します。対象期間と「大会当日のメタ予測ではない」旨は典型リスト画面に明記します。

## ひとり回し

1. 大会を取得したら「デッキを選んでひとり回し」を開き、選手名・デッキ名・カード名で探します。「最近の環境から」で取得した実リストからも開始できます。
2. リストの「このデッキをひとり回し」を押し、初手をキープするかマリガンします。大会全体の準備表を作る前でも開始できます。
3. 次回はトップ画面の「ひとり回しの続き」で最後のゲームを直接開けます。大会検索のやり直しは不要です。

手元のリストを使う場合は、トップ画面の「手元のリストでひとり回し」に英語カード名のArena／MTGOテキストを貼り付けます。メイン60〜250枚・サイド15枚以下で1リストずつ読み込みます。大会URLやトークン検索は不要です。`title`・`url`（任意）・`mainboard`・`sideboard` を持つJSONも使えます。カード行は `{"name":"Island","count":4}` 形式です。

保存先は同じブラウザのローカル領域です。選択途中・サイド入替・Undoの履歴も復元します。別のブラウザや端末には同期しません。「続き」は最後に開いたゲームへの入口で、他のデッキの保存を消すものではありません。

大会・環境から選んだ実リスト、または自分で貼り付けたリストを使います。検証用の固定10種類を、検索前の最新メタやトークン候補として表示する入口はありません。

「サイド入替」で、入れるカードと抜くカードを1枚ずつ選べます。メイン枚数が揃ったら「この構成で初手から」で開始。「最初から」やマリガンは入れ替えた構成を保ちます。元の構成へ戻すときはサイド入替の「元のリストへ戻す」を押して開始してください。入れ替え直前の盤面へは「戻す」で戻れます。

ゴブリンの砲撃を選ぶと「まとめて砲撃」を使えます。生け贄にする順にチェックして実行すると、1体ずつ相手へ1点を与え、途中の誘発も処理します。必要な選択で止まったら、その選択後に残りを続けます。ライフ・毒・空の山札からのドロー・対応する特殊勝利による決着は、到達したターンとともに表示します。山札が0枚になっただけでは敗北にしません。

計画を持つ手札は、選ぶと「計画」が出ます。支払い後は手札の上に計画済みカードが残り、後の自分のターンに「0マナで唱える」を押せます。装備品は選んで「装備」、またはダブルクリックして装備先を選びます。支払い・付け替え・P/Tと能力は自動で反映します。

ホガークの召集・探査では、支払える組み合わせを先に選択します。召集する戦場のクリーチャーと探査する墓地のカードを確認し、必要なら選び直して確定してください。《マイコシンスの格子》はパーマネントのアーティファクト化、各領域の無色化、色マナ支払いの代用を反映します。無色マナ指定のコストとマナの使途制限は引き続き適用します。

《一つの指輪》は、唱えて登場した場合の保護、タップによる負担カウンターとドロー、自分のアップキープのライフ喪失を処理します。保護は指輪が離れても次の自分のターンまで続き、自分へのダメージと対象選択を防ぎます。フェッチなどのライフの支払い、負担によるライフ喪失は防ぎません。

焦熱島は「生け贄にして1枚引く」、超能力蛙は「1枚捨てて +1/+1」「墓地3枚を追放して飛行」を使えます。《発掘 / Unearth》などのサイクリングも手札の操作に表示します。信仰無き物あさりは引いた後に捨てる2枚、異世界の凝視は諜報3の行き先だけを選びます。墓地の対応カードを選ぶと、専用コストを使うフラッシュバックも選べます。キーワード能力の「発掘」は各ドロー時に選び、切削と墓地からの回収を自動処理します。

全画面の中央が戦場、下が手札、右が山札・墓地等です。選択したカードの操作は手札の上に表示します。右クリックまたは「詳細」で拡大画像と細かい操作を開きます。PCではマウスを重ねても拡大できます。

果敢、媒介者の諜報、コーリ鋼のモンク生成は、呪文を唱えたときに自動で誘発します。対応する呪文本文も、対象・占術・諜報・装着などの選択が必要なところまで自動で進みます。同時誘発は既定で強化→諜報→モンク生成の順です。別の順を使う場合はスタック画面の「誘発の解決順を毎回選ぶ」をオンにします。応答を挟みたいときは「選択が必要になるまで自動進行」をオフにし、Spaceで1つずつ解決します。

画面上の「呪文 N」で、そのターンに唱えた回数とスタックを確認できます。コーリ鋼は2つ目の呪文で誘発し、生まれたモンクの果敢は次の非クリーチャー呪文から誘発します。果敢の強化はカウンターとは別に表示し、次のターンへ進むと消えます。媒介者の昂揚は墓地のカードタイプを参照します。旧保存データには唱えた回数がないため、初回の再開時だけ現在の回数を設定します。選択途中の保存・Undo/Redoにも対応しています。

- 初回は7枚を引いた状態で開きます。先手/後手を選び、キープかマリガンを選択します。以前保存した同じデッキがある場合は自動で再開します。上部の「最初から」で盤面・ライフ・マナをリセットして引き直し、直後の「戻す」で再開前の盤面に戻れます。
- マリガンするたびに7枚引き直します。キープ前に、マリガン回数と同じ枚数を手札から選び、「キープ」で山札の下へ戻します。
- キープ後は「1枚引く」「次のターン」を使えます。次のターンでは戦場をアンタップして1枚引きます。先手の第1ターン開始時だけ自動ドローしません。
- 手札はカード画像で横並び表示します。狭い画面では横へスクロールでき、カードを押すと選択できます。
- 手札をダブルクリック、選択して `Enter`、または戦場／スタックへドラッグしてプレイします。土地は戦場、呪文はスタックに置きます。「自動タップ」がONなら、プールを優先して使い、必要な対応マナ源で支払います。認識できる軽減・増加・使途制限を反映し、色・無色・不特定・混成・ファイレクシア・Xに対応します。X、ライフ、対応する追加コストや代替コストは必要な選択をしてから支払います。土地1枚から2色分を同時に出すことはありません。
- 青く光る手札は自動支払いの目安です（Xは0）。対応するコスト変更、唱えるタイミング、一部の対象の有無を確認します。代替支払いのすべての組合せを先読みするものではないため、光っていなくてもカードを選んで計画・想起・ピッチ等の入口を確認できます。支払うカードやマナを変えるときは「支払いを調整」、未対応の支払いは「手動処理」を使います。
- スタックの「本文の操作」から効果を処理し、`Space` または「解決」を押すと、最後に置いた呪文から戦場／墓地へ移します。解決待ちがある間は次のターンへ進めません。打ち消された呪文などは直接墓地／追放へ移せます。
- 計画・ワープ・衝動ドロー等で追放した対応カードは、使用できる領域・期限・コストを確認してプレイします。使えるカードは手札の上にも表示します。未対応の効果で追放から使う場合は、本文を確認して手動の「追放からプレイ」を使います。土地はプレイ回数と出し方を確認します。
- 戦場は上段のクリーチャー、下段の土地、左のその他に分かれます。ドラッグで別レーンへ移動・同じレーン内で並べ替えできます。墓地・追放には右のボタンへドロップできます。各ゾーンの一覧はボタンで開き、選択カードを手札／戦場へ戻せます。
- 土地をダブルクリック、または選択して `T` でマナを出します。対応する土地・マナクリーチャー・アーティファクトは、召喚酔い・使途制限・追加コスト等を反映します。複数色やダメージ／ライフ支払いがある場合は選べます。フィルター等の対応する能力はカード別操作から起動できます。未知のマナ能力は本文を確認し、「マナ」でプールを調整してください。マナ能力のないカードや複数選択の `T`、「全タップ」はタップ状態だけを変えます。`Ctrl` を押しながらクリックすると複数選択できます。
- 「マナ」で各色を増減できます。ステップ／フェイズを進める際は同パネルの「マナを空にする」を使います。次のターンでは自動的に空になります。アンタップだけでは出したマナを取り消さず、「戻す」で起動ごと取り消します。
- 墓地・追放・スタックは空でも置き場所を表示します。山札へ戻す場合は「一番上」「一番下」「戻して混ぜる」へドロップするか、カードを選んでボタンを押します。ゾーン一覧からドラッグすると移動先が見えるようになります。
- 《定業》《思案》《渦まく知識》《表現の反復》などはカードの行き先・順番だけを選び、続くドロー等を自動処理します。《表現の反復》は手札・山札の下・追放へ1枚ずつ。追放カードは通常のコスト・土地回数に従い、このターン中にプレイできます。
- 《稲妻》などは唱える前に対象を選び、解決時にダメージを反映します。《溶岩の投げ矢》は墓地で選択して「フラッシュバック」から対象と生け贄にする山を選べます。《変異原性の成長》のライフ支払いも選べます。
- 戦場の《ミシュラのガラクタ》をダブルクリックするか「ガラクタを起動」を押します。山札の対象を選び、上のカードを確認すると、次のターンのアップキープに自動で引きます。「次ターン」で相手ターンを経て次の自分のターンへ進み、「ツール → 相手のターンへ」なら相手ターンに止まって起動やフェッチができます。
- 「攻撃する」でクリーチャーを選び、必要なら強化呪文を唱えてから「戦闘ダメージ」を押します。ブロックなしの合計ダメージをライフへ反映。召喚酔い・速攻・警戒・絆魂・感染・先制／二段攻撃に対応します。先制攻撃後も通常ダメージの前で停止します。
- 「本文の操作」は未対応の効果を手動で処理する入口です。「ツール → このデッキのカード別操作」で自動対応と残る操作をカードごとに確認できます。山札を見るだけでシャッフルはしません。
- 「山札 操作」の「探してシャッフル」では、画像とカード名で検索し、選んだカードを移動した後に残りの山札を自動シャッフルします。「上からX枚」は見るだけ、複数ドロー、切削、追放を分けて扱い、見るだけでは順番を変えません。
- 戦場のフェッチランドを選び `F` を押すと、取得可能な土地だけを表示します。土地と出し方を確定すると、生け贄・必要なライフ支払い・戦場への移動・シャッフルまでまとめて処理します。ショックランドはタップイン／2点支払いを選択。基本土地フェッチは0点、虹色の眺望は1点、寓話の小道は取得後の土地が4枚以上ならアンタップします。諜報ランドはタップインし、シャッフル後の一番上を残すか墓地へ置くか続けて選べます。
- フェッチ確定前の `Esc` は盤面を変えずにキャンセルします。「土地を見つけずに終了」はコストを支払ってシャッフルします。フェッチ1回は `Ctrl+Z` 1回で支払い・移動・山札の順序まで戻せます。`F` は対応する単一土地のフェッチ用です。探検の地図など別の探索能力はカード別の起動を使い、未対応の探索は山札操作で処理します。条件付きタップインの一部は本文を確認して出し方を選びます。
- 自分と相手のライフは `±1` / 数値入力で管理できます。「ツール」に双方の毒、自分のエネルギー、トークン作成、コイン・ダイス、保存・再開・ゲームログをまとめています。
- 戦場のカードには任意カウンター、表示用P/T、メモを付けられます。トークン／カスタム・パーマネントの作成、コピー、裏向き、両面カードの面切替、コイン、d6、d20にも対応します。
- 「元に戻す」「やり直す」とクリック可能なゲームログは最大60状態を保持します。「保存」は盤面と履歴をブラウザへ保存し、同じデッキを次に開いた時に再開します。

主な操作キーは `1`〜`9`（左から手札を選ぶ）、`B`（戦場）、`G`（墓地）、`E`（追放）、`H`（手札）、`F`（フェッチ）、`T`（選択カードのタップ）、`U`（全アンタップ）、`D`（1枚引く）、`N`（次ターン）、`K` / `M`（キープ／マリガン）、`L`（山札操作）、`Ctrl+Z` / `Ctrl+Y`（Undo / Redo）、`?`（キー一覧）です。Macは⌘にも対応します。検索欄から `↓` で候補へ、`Tab` で操作を選んで `Enter` で決定できます。入力中・IME変換中・キーの押しっぱなしではゲーム操作せず、Ctrl+L等のブラウザ操作も維持します。

`Enter` は選択した手札のプレイ、`Space` は初手のキープ／解決待ちの解決／次ターンです。ボタンにフォーカスがある場合、Enter・Spaceはそのボタン本来の操作を優先します。

Modern・Standard・Legacy・Pioneer各10種類の実リストで、メインとサイド後の勝ち筋を検証しています。これは検証した経路と能力の範囲であり、全カードの全相互作用の対応を意味しません。自分の展開を練習するための卓なので、相手の実際の手札・盤面・ブロックは保持しません。

対応する自動処理を手動で重ねて実行しないでください。未対応の能力・相互作用は本文を確認して手動処理できます。特殊な盤面ではカード別操作からそのカードの自動能力をオフにできます。基本ルールは [公式ルール](https://magic.wizards.com/en/rules)、設計と対応範囲は [goldfish-rules.md](goldfish-rules.md)、実リストの経路と検証条件は [goldfish-top10.md](goldfish-top10.md) を参照してください。

## このツールが扱うもの

大会のリストから、必要なトークン現物と、対戦・放送中に状態を見失わないための補助物を調べます。各項目で関連カードと実際の採用デッキを確認できます。

- トークン
- 紋章
- 物理的なコピー・トークンやコピー用マーカー
- 裏向き補助（予示・戦慄予示・偽装・変装・変異・大変異）
- 計画済みカードの追跡補助（他のカードで計画済みになる場合も含む）
- ワープの追放と、後のターンに唱えられるカードの追跡補助
- 準備済み／未準備の状態を示す補助。発生源を開くと準備呪文名も確認できます
- エアベンドやパラダイムなど、除外ゾーンに置かれ後で唱えるカードの追跡補助
- 昼夜マーカー
- 都市の承認、不朽の物語、統治者、指輪、速度、イニシアチブ／ダンジョンと部屋のトークン
- 予顕・出来事・待機・反復等の追放中のカード、督励・怪物的・高名・容疑等の状態
- エネルギー・毒・経験・放射能、ストーム回数の補助
- 相棒として公開する場合の補助、両面カードを差し替える場合の補助（必要な場合のみ）

対象全体は [補助物の点検記録](auxiliary-coverage.md) にまとめています。

ゲーム中の「準備済み」と、このアプリの「用意した／準備済み」チェックは別です。補助物は汎用マーカー等で用意でき、公式の専用カードが必須という意味ではありません。大会の登録デッキ名は、別のデッキ名へ自動推定し直さず表示します。

## スコープ外

通常の数値カウンターを個別のカード項目にはしません。プレイヤー資源の補助カードと、カウンターがなくても続く状態は別途表示します。

- +1/+1カウンター
- 時間カウンター
- 忠誠カウンター
- Impending の待機カウンター

`copy` という単語がOracleに出るだけでは、コピー・トークン扱いにしません。インスタント／ソーサリーのコピーだけであれば現物を追加しません。パーマネント呪文のコピーは戦場でトークンになるため対象にします。

## 検索デッキ数の目安

「絶対に出し漏れがない」ことは、1人だけが使うローグカードまで考えると保証できません。このツールでは、使用率 `p` 以上の発生源を、指定した信頼度で少なくとも1回見るための目安を使います。

```text
n >= log(1 - confidence) / log(1 - p)
```

95%で拾う目安:

| 使用率 | 必要デッキ数 |
|---:|---:|
| 5%以上 | 約59デッキ |
| 2%以上 | 約149デッキ |
| 1%以上 | 約299デッキ |
| 0.5%以上 | 約599デッキ |

検索デッキ数は20-600件の範囲で扱います。薄いローグ採用を古いデッキで水増しするより、国内ソースや大会固有URLを足して母集団の質を上げる方を優先します。

「検索済みの総数」が取得件数です。一覧は最初の10件を表示し、「全○件を表示」で残りを開けます。設定した検索数は上限で、対象期間に取得できるリストが足りなければ上限未満で終了します。ソース別の取得件数も確認してください。上限に届いても、全取得元を均等に集計したことを意味しません。

## キャッシュ

### 配布後の禁止改定を反映する

フォーマットを選び「環境データを更新」を押してください。環境履歴・セット情報・選択フォーマットの候補カードを取得し、再起動なしで反映します。完了後に検索し直してください。「抜いた」チェックは保持します。失敗時は前回の環境データが残ります。最終取得日時と公式情報の確認範囲は別に表示します。詳細と初回の本体入れ替えについては[環境更新](environment-updates.md)を参照してください。

ローカル版の巡回済みページは `.cache/pages` に保存されます。公開版では同じキャッシュをサーバー側のR2に保存し、デプロイ後も利用します。

- `巡回キャッシュを使う`: 保存済みページを優先
- `今回は再取得`: キャッシュを無視して再取得
- `キャッシュ削除`: 保存済み巡回ページを削除

`巡回キャッシュを使う` がオンでも、巡回元のインデックスページ（新しいデッキが現れる入口）は6時間で自動的に再取得します。個別デッキページは公開後に変化しないため、期限なしで再利用します。取得に失敗した場合は、期限切れキャッシュがあれば代替として使います。

トップメタのフォーマットページとアーキタイプ一覧も入口ページとして6時間で再取得し、典型例の個別デッキページは通常の個別ページと同じく再利用します。

Scryfallの候補カード検索もローカル版では `.cache/scryfall/`、公開版ではR2に保存します。APIのレート制限や一時障害が起きた場合でも、期限切れキャッシュがあれば代替使用して検索本体を続行します。Scryfall由来データは24時間キャッシュし、検索系APIは低頻度に絞ります。初回や再取得時は外部サービスの待ち時間で検索が長くなることがあります。

`.cache/` はGit管理しません。

## 利用と外部サイト

このツールは身内の大会準備用途の非公式Fan Contentです。WAF、Cloudflare、robots.txt、明示的なアクセス制限を回避して巡回する用途ではありません。巡回できないサイトは、手動で公開デッキURLを足すか、別の公開ソースを使います。

## トラブルシューティング

新セット準備モードの対象セットは、コードを知らなくても名前から選べます。大会日・フォーマットを変えると候補とおすすめを更新し、適用日を自動入力します。大会後の候補は選べません。説明が「仮置き」の場合は公式の構築適用日を確認し、必要なら日付を調整してください。一覧にない場合だけ手動指定を使います。

「配信元が旧形式」の更新エラーは、作成者が対応データをGitHubに公開するまで解消しません。手元の設定では直せません。更新前のデータを保持するため、通常の検索は続けられます。

抜き出し先と「手元のセットから別版を探す」は、通常の拡張セット・基本セットに加え、そのフォーマットへ新カードを収録する製品の紙の発売済み版を対象にします。モダンではMH1・MH2・MH3・LTR・ACRも同じセット欄に並びます。統率者版（M3C・LTC等）は別製品として判定し、モダンでは除外、レガシーでは統率者・特殊ドラフト製品も対象にします。マスターズ等の再録専用製品、Secret Lair、プロモ、特殊フレームは対象外です。同名でも色・サイズ・タイプ・能力が違う版は代用しません。これは準備する製品の範囲であり、トークン自体にフォーマットの使用可否を課すものではありません。

対象セット版が見つからない必要トークンは削除せず、仕様と発生源を「別途用意するもの」に残します。印刷検索の失敗は未確認と区別し、対象外の製品画像を抜き出し候補として表示しません。空白カードなど別の方法で準備したら「用意した」にチェックしてください。汎用のコピー・裏向き用マーカー等は「汎用マーカー・補助カード」にまとめます。日本語画像は同一仕様・同一製品で見つかったものだけを使用します。

「同梱版（本体付属）」は検索に使った環境履歴の出所です。トークン画像の取得失敗を意味しません。未来の大会日の使用可否は確定できないため、取得時点の使用可否である旨の注意は残ります。

| 症状 | 対処 |
|---|---|
| 「Node.js が見つかりません」と表示される | https://nodejs.org/ja/ からインストールして再起動 |
| ブラウザが開かない | 手動で `http://localhost:5177` を開く |
| `address already in use` と表示される | 最新の `start.bat` では起動済みの画面を再利用します。古い版なら黒いウィンドウをすべて閉じてから再実行 |
| ログが見えない | 画面右下のログパネルが開いているか確認する。検索開始後は現在の検索ログだけを表示するため、過去の検索ログは自動で混ざりません |
| 「インストールに失敗しました」と表示される | ネット接続を確認して `start.bat` を再実行 |
| 黒いウィンドウが一瞬で閉じる | PowerShellでこのフォルダを開き、`.\start.bat` を実行して表示されたエラーを確認 |
| `npm install` が権限エラーになる | PowerShellを開き直すか、必要なら管理者として実行 |
