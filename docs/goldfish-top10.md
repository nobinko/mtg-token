## 共通処理

- マナは発生、制限、支払い、余剰を分離。色・無色・不特定・混成・ファイレクシア・Xを扱い、即席で色マナを払わない。制限付きマナの余りは別用途に流用しない。督励由来の速攻と次のアンタップ省略を記録する。
- 詠唱・領域移動・登場・死亡・カウンター・攻撃・戦闘開始・終了ステップを共通イベントとして処理。誘発はスタックに積む。対象・モード・コストは該当するタイミングで選択する。
- 領域を移動したカードは別オブジェクトとして扱う。古い対象を再利用せず、授与・土の技・一時コピー・刻印・章・期限を掃除する。
- 選択中の状態を保存できる。キャンセル前には払わず、支払いと起動を履歴にまとめる。コンボ20回も1回のUndoで戻る。追放から使用可能なカードは手札の上にも表示する。
- 保存は重複するカード情報・履歴を共有して小さくする。旧形式も読み込め、容量不足時は他の保存ゲームも内容を保ったまま圧縮する。保存失敗は画面下部へ表示する。
- 原文が検証済みOracleと一致するアダプターを使用する。カード名だけで未確認の本文を実行しない。ルールに関わる修整と全カードの任意効果を統一的に解釈する、完全な総合ルール実装ではない。

## 処理の境界

相手の手札・山札・戦場・ブロッカー・優先権はモデル化していない。相手のカードを対象にする除去・打ち消し等には「相手の対象」を選べる入口を用意し、自己側の支払い・誘発・呪文数を処理して続行する。相手のカードが実在するか、対象条件に合うかは判定しない。相手のライフへの火力とブロックなしの戦闘ダメージは実際に更新する。

検証範囲は、このスナップショットの10リストの主要ルートと下記の能力別場面。全カードの全相互作用、任意の継続的効果・置換の組み合わせ、完全な優先権や全ステップを備えた対戦エンジンの完成を意味しない。未知のOracleや対応外の効果には本文確認と盤面修正を残している。

### 実リストでの決着と実画面

- [Doomsday / WeareVenom](https://mtgtop8.com/event?e=92449&d=902298&f=LE): 60/15枚を保持し、シャッフルの固定シード17から開始。Underground Sea→Dark Ritual→Doomsday、Street WraithでOracleを引き、次ターンのLotus Petalと追加サイクリングから神託者でT2勝利。途中のカード・マナ追加はない。
- サイド後は同じ実リストのPonder1枚をFlusterstorm1枚と交換し、同じ初手生成からT2勝利まで確認。この交換は処理検証用であり、対面別のサイド案ではない。固定シードによる一経路なので、平均速度・勝率・すべての初手を示さない。
- ブラウザーは環境検索Legacy・大会日2026-10-19・300リストから、[Legacy Challenge 32 / empiricism](https://www.mtgo.com/decklist/legacy-challenge-32-2026-10-1812856606) の61/15リストを開いた。通常の初手にヤヴィマヤ・不毛の大地・壌土からの生命があり、T1ヤヴィマヤ、T2不毛の大地、土地2枚の自動タップでLoamを0対象で解決。カード・マナを足していない。
- T3のドローが発掘選択で停止。ひとり回しを閉じて開き直し、保存済みの選択から発掘3を実行。山札53→50、手札5→6、墓地1→3を画面で確認した。`.cache/goldfish-dredge-choice-20261020.png` と `.cache/goldfish-dredge-result-20261020.png` に記録。途中、払えるはずのLoamが止まるヤヴィマヤの欠落と、発掘待ちを「山札が空」と扱う表示を修正した。
