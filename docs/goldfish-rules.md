# ひとり回しのルール処理

Modern・Standard・Legacy・Pioneer各10種類の実リストを使った検証と拡張は [goldfish-top10.md](goldfish-top10.md) を参照。この40種類は内部の固定検証資料で、アプリが大会・時期・フォーマットを選ぶ前に提示する順位ではない。以下の初期実装の対応表に加え、カード別プログラム・イベント処理・代替支払い・コンボ反復を追加している。

## 方針と責務

デッキの実際のOracleを読み、検証した能力だけを決定的に処理する。UI上のボタンごとに能力を足さず、支払い・唱えるイベント・誘発・スタック・選択・解決を独立させる。任意の英文を正規表現だけで実行する汎用ルールエンジンにはしない。

- `goldfish.js`: 不変のゲーム状態遷移と領域移動。キーボード、ドラッグ、手動支払い、追放からのプレイが同じ `playGoldfishCard` を通り、唱えるイベントを1回だけ発生させる。単なる領域修正は唱えたことにしない。
- `goldfish-mana.js`: 支払い計画と支払い。支払いと唱えるイベントは1回の履歴にまとめる。失敗した計画は元の状態を変えない。
- `goldfish-sideboard.js` / `goldfish-sideboard-ui.js`: 登録リストとゲーム中の各領域を分離し、メインとサイドの入れ替え・初手からの再開を行う。元のメイン枚数を保ち、登録カードの総数を超えて増やせない。
- `goldfish-batch.js`: 選択したクリーチャーの砲撃を1回ずつ実際に起動する。途中の誘発・選択・保存再開を扱い、発生源や選択した対象が別オブジェクトになれば残りを中止する。
- `goldfish-storage.js`: 内容が等しい保存データを圧縮する。読み戻したゲームの配列やオブジェクトは独立させ、別のイベント列や履歴を意図せず書き換えない。
- `goldfish-action-definitions.js` / `goldfish-actions.js`: 計画、装備、対応する起動型能力のコスト・タイミング・選択。支払いを共有し、起動を唱えるイベントに数えない。装備先は宣言時と解決時に確認する。
- `goldfish-rules.js`: DOMに依存しない能力の識別、唱えたイベントへの反応、選択、解決、表示用特性。検証済みカード名とOracle条件、または独立した果敢キーワードを使う。公開関数が複製したdraftだけを更新する。
- `goldfish-spells.js`: 検証済みOracle本文を解決手順へ変換。対象の宣言・再確認、占術・ドロー等の継続可能な解決、致死ダメージとタフネス0以下の処理を担当する。
- `goldfish-objects.js`: 領域移動、別オブジェクト化、装着の解除、フラッシュバックの追放を共有する。
- `goldfish-card-programs.js` / `goldfish-engine.js`: 検証済みOracleの命令列、イベント、対象を固定した解決と保存可能な選択を扱う。
- `goldfish-format-programs.js` / `goldfish-sideboard-programs.js` / `goldfish-advanced-spells.js`: フォーマットをまたぐ呪文・モード・サイドカードの検証済み命令列。
- `goldfish-format-runtime.js`: 解決中の即時詠唱、親の解決への復帰、エネルギーやコピーの予算、機体・墓地・追加ターン等の処理。
- `goldfish-extra-costs.js`: 追加コスト・代替コストの選択と検証。選択前にマナを払わず、キャンセル時には資源を変更しない。
- `goldfish-format-permanents.js`: 対応する登場・死亡・攻撃・ターン誘発、忠誠度・起動・継続的修整。名前の登録は全能力の完了宣言ではなく、個々の能力とテストが対応の根拠となる。
- `goldfish-entry-copies.js`: 登場前のコピー選択、コピー可能な特性、名前・P/Tの例外、追放の独立した誘発。カウンター・支払い済み追加コスト・ID・装着先をコピーしない。
- `goldfish-modal.js`: モード・対象・連繋・追加コストを支払い前に確定する。
- `goldfish-constraints.js`: 対応済みの起動禁止、詠唱禁止、登場誘発の抑制を共有する。領域移動の檻・安らかなる眠り・蘇生の置換は `goldfish-objects.js` が処理する。
- `goldfish-combat.js`: ブロックなしの攻撃宣言と戦闘ダメージ。宣言後と先制攻撃後に呪文を挟める。
- `goldfish-choice-ui.js`: 対象、振り分け、山札の順序、手札を戻す順序、攻撃クリーチャーなどの選択画面。ゲーム状態の処理はエンジンへ渡す。
- `goldfish-ui.js`: 状態を表示し、選択結果をエンジンへ渡す。山札を調べる、カウンターを置くなど従来の手動操作を保持する。
- `goldfish-storage.js`: v2のゲーム状態・選択・履歴を、重複情報を共有する保存形式へ変換する。旧JSON形式も読み込む。容量不足時は既存のゲーム保存を内容を保持して圧縮し、なお保存できない場合はUIへ失敗を返す。

## 操作体験の完了条件

目的は、大会の準備表から選んだ実デッキを使い、利用者がプレイの判断に集中できること。「唱える → 誘発する → 必要な選択 → 盤面への反映」を一続きの操作として評価する。指示に書かれたボタンだけを増やして終えない。

1. **判断と定型処理を分ける。** 唱えるカード、意味のある解決順、諜報の行き先、任意の装着は利用者が決める。対応する支払い・タップ・誘発検出・修整・期限切れはツールが処理する。応答を挟む停止とUndoを残し、自動処理がプレイの選択を奪わないようにする。
2. **状態と結果が見える。** 今唱えられる手札、現在解決する能力、選択を待つ理由、変化したP/Tと生成トークンを盤面と結び付けて示す。色だけに意味を持たせず、ラベルと数値でも伝える。将来のアニメーションや音は因果関係を伝えるために使い、操作待ちを増やさない。音・演出は現時点の実装済み機能ではない。
3. **実デッキで一連の操作を確かめる。** 単体テストの件数だけで使いやすさを判定しない。土地を置き、支払い、呪文を唱え、複数誘発を並べ、諜報・生成・装着を選び、さらに唱え、次のターンへ進む流れを実画面で確認する。途中のUndo/Redo、閉じて再開、390pxでの選択も含め、未対応部分は明示する。

## 状態の契約

`stack` が唯一の解決順の正本。既存の呪文カードと `kind: ability` の能力オブジェクトを同じ配列に保持し、末尾から解決する。誘発はカード枚数・カード画像操作・メタデータ補完の対象外で、墓地へ移動できない。

`rules` はイベント番号、このターンの呪文数・土地プレイ数、選択待ち、解決中の命令列、戦闘、アクティブプレイヤー、ターン通し番号、遅延ドローを保持する。選択待ち・選びかけの振り分けも保存・Undo/Redoの対象。選択中は別の呪文や領域操作を受け付けない。コーリ鋼はトークン生成後から装着選択の終了まで1つの能力を解決中として扱う。

各カードの `incarnation` は領域を移るたびに変わる。誘発の発生源と装着先はカードIDとincarnationを組にして参照する。戦場を離れて戻った同じカードに古い果敢を適用しない。諜報・トークン生成は発生源が消えても解決する。

「この効果の解決中に唱える」は通常の後日プレイ許可と区別する。親の命令列・使用予算・詠唱候補を保存し、対象と追加コストの選択後に一度だけ唱え、親の解決へ復帰する。誘発はその後に処理する。出来事・エアベンド・ワープ・計画・衝動ドローは、それぞれの期限と使用可能な領域を持つ。

コピーは元の印刷された特性を保存し、恒久的なコピーをターン終了時に解除しない。領域を移動したときには元に戻す。伝説ルールの画面はコピー元・タップ状態・カウンターを併記し、同名のカードを見分けられる。対象の配分はスタックに積む際に固定し、対象が消えても残りへ配り直さない。

大釜の能力継承はコピーと分ける。戦場の大釜と追放カードの現在の参照から起動型能力を導出し、＋1/＋1カウンターのあるクリーチャーへ付与する。登場誘発や常在型能力を複製しない。発生源が離れた後もスタック上の能力は解決するが、戻った大釜には以前の追放を関連付けない。一度だけの起動は支払い時に記録し、打ち消しでは戻さず、領域変更で消す。

奇跡は実際の最初のドローから誘発し、ドローを発掘で置換した場合には誘発しない。複数枚引く呪文の途中で別の呪文を解決せず、元の呪文の処理が終わってから、奇跡の誘発を通じて唱えるか選べる。

トークンとパーマネントのコピーは戦場以外へ移動すると消滅させ、山札へ混ぜて再び引くことを防ぐ。死亡などの未対応誘発は手動処理する。

`temporaryEffects` はターン期限付きでカウンターと分ける。表示時に基礎P/T、手動の基礎P/T指定、+1/+1と-1/-1カウンター、一時修整、対応する常在型修整を合成する。次のターンへ進む際、一時修整と呪文数をリセットする。完全な継続的効果の種類別処理を実装したものではない。

保存エンベロープv2と既存キーを維持し、`rules.version = 1` を加える。旧ゲームの過去の唱えた回数を推定せず、再開時に利用者に1回設定してもらう。最初から始める場合は既知の0回になる。

## 操作と対応範囲

唱えると対応能力をスタックへ積む。既定は強化→諜報→モンク生成の順で、対応する呪文本文も必要な選択まで自動で進める。この順は操作の既定値で、別の順と等価という意味ではない。「誘発の解決順を毎回選ぶ」で利用者が順序を決められる。「選択が必要になるまで自動進行」をオフにすると、Spaceで1つずつ解決できる。未対応の本文では停止する。

| 能力 | 自動処理 | 利用者の選択 |
| --- | --- | --- |
| 果敢（カード・生成モンク） | 非クリーチャー呪文に誘発、解決時+1/+1、期限切れ解除 | 同時誘発の順序 |
| ドラゴンの怒りの媒介者 | 非クリーチャー呪文に諜報1、墓地4タイプによる昂揚のP/T・飛行表示 | 上に残す／墓地へ |
| コーリ鋼の短刀 | そのターンの2つ目の呪文に誘発、白の1/1果敢モンク、装着時+1/+1・トランプル・速攻表示、装備コストでの付け替え | 生成したモンクに装着するか、通常の装備先 |
| 精鋭射手団の目立ちたがり | 非クリーチャー呪文でターン終了まで+2/+0、計画と後のターンの無料詠唱 | 唱えるか計画するか、計画後いつ唱えるか |
| ミシュラのガラクタ | 生け贄、対象の山札を見る、次のターンのアップキープにドロー | 対象プレイヤー、見たカードの確認 |
| 超能力蛙 | 戦闘ドロー、手札を捨てて+1/+1カウンター、墓地3枚追放でターン終了まで飛行 | 攻撃、捨てる1枚、追放する3枚 |
| 焦熱島等の `{1}, {T}, Sacrifice this land: Draw a card.` | 支払い・タップ・生け贄、解決時ドロー。起動元の土地を同時に支払いへ使わない | 起動するか、必要時のライフ支払い |
| マナのみをコストとする通常の計画・装備・サイクリング | 完全なキーワード行を識別し、計画の追放・装備先・捨てるコスト・ドローを処理 | 計画／サイクリング、装備先 |

呪文本文は完全なOracle命令との一致を確認し、次の20種を扱う。

| 呪文 | 自動処理と選択 |
| --- | --- |
| Preordain / Consider / Opt / Serum Visions | カードごとの正しい順で占術・諜報・ドロー。上／下／墓地を選択 |
| Faithless Looting / Otherworldly Gaze | 2枚引いてから2枚捨てる／諜報3。墓地からはフラッシュバックの専用コストを支払い、スタックを離れる際に追放 |
| Ponder / Brainstorm / Sleight of Hand | 山札の順序、任意のシャッフル、手札から戻すカードと順序を選択 |
| Expressive Iteration | 手札／下／追放へ配分。追放カードの使用期限と土地1回を確認 |
| Manamorphose | 2マナの色を選んで加え、その後1枚ドロー |
| Lightning Bolt / Lava Dart / Unholy Heat | 唱える前に対象、解決時に再確認。相手／自分のライフ、クリーチャーの致死ダメージを反映。Heatの昂揚は解決時に判定 |
| Mutagenic Growth / Violent Urge | 一時修整、先制攻撃、解決時に昂揚なら二段攻撃。Growthの2ライフ支払いは明示的に選択 |
| Vapor Snag / Unearth / Persist / Reanimate | 対象の領域移動、対象条件、カウンター、ライフ損失、対応するETBを処理 |

Lava Dartは墓地から対象と生け贄にする山を選べる。支払い・唱えるイベントを一括で記録し、解決・打ち消し・その他のスタック離脱で追放する。山を生け贄にしただけでは唱えたイベントは発生しない。

「攻撃する」はブロックなしの戦闘。召喚酔い、速攻、防衛、警戒、昂揚した媒介者の攻撃義務、絆魂、感染、先制／二段攻撃を扱う。攻撃宣言後に強化呪文を唱え、「戦闘ダメージ」で現在のパワーを反映する。先制攻撃と通常ダメージの間でも停止する。戦場を離れて戻ったカードは元の攻撃に参加しない。

「次ターン」は相手のアップキープの遅延誘発を処理してから自分の次のターンへ進む。相手ターンで起動・フェッチ・インスタントを使いたい場合は「ツール → 相手のターンへ」。ガラクタのドローは解決時や追加アップキープで早めず、次のターンのアップキープへ積む。自分のアップキープのスタックが空になるまで通常ドローを待つ。相手の山札はモデル化していないため、ガラクタで相手を選んでもカードを捏造して表示しない。

新しいモンクは、それを生成した誘発の原因となった呪文の果敢を得ない。コーリ鋼自身がスタックにある間は誘発しない。クリーチャー呪文も2つ目の呪文の数には含む。打ち消された呪文も唱えた回数から引かない。各コピーのコーリ鋼・媒介者・果敢は別々の能力として処理する。

未実装の唱えた時・対応する自己ETB・自己攻撃誘発は自動実行せず、条件・効果を確認する停止を出す。すべての誘発構文を認識できる保証はない。未掲載の本文・起動型能力、能力喪失・付与、トークン倍化、置換効果、能力による攻撃制限、相手の盤面・ブロック・優先権、プロテクション等の追加対象制限、完全なフェイズ／ステップ、全般的な状況起因処理、特殊な装備・計画コスト、装備品の未掲載の能力は手動。通常の装備品は定数のP/T修整と対応キーワードを表示する。プロテクション等の複雑な装備先は自動選択から除外する。カード別操作に対応範囲と自動能力をオフにする入口を表示する。アリーナ全体のルール互換を意味しない。

新しい能力を追加するときは、実際のデッキでの使用、公式Oracleと裁定、イベント・選択・解決の契約、複数発生源・発生源消失・Undo・再開の回帰試験を一組で追加する。置換効果や対戦処理はこの層に無理に混ぜず、別のイベント前処理・優先権・対象検証として拡張する。

## 残る拡張（設計上の候補）

1. **実デッキの残りの能力**: カード別対応表を起点に、未対応の追加コスト、死亡・アップキープ誘発、追加の起動型能力・呪文本文を追加する。カード名だけで対応済みにせず、個々の能力とコストを検証する。
2. **ターンとルール干渉**: 完全なステップ、優先権、置換効果、継続的効果、死亡誘発を拡張する。解決中の保存から再開してもコストや効果を重複させない。
3. **対戦相手を含む戦闘**: 相手の盤面、ブロック、ダメージ割り振り等は独立した範囲。現在のブロックなし戦闘の成功を対戦全般の完成とは扱わない。

この候補は将来の実装順序を示すもので、未実装部分の完成や本番公開を示すものではない。
