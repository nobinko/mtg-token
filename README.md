# MTG Token Finder

フィーチャー卓の配信準備で、バルクのトークン束から必要な現物を抜き出すためのWebツールです。スマホ・PCから使える公開版と、PCで起動するローカル版があります。

このツールは「カード検索」ではなく「現場の準備表」です。デッキリストを集め、トークン・紋章・物理的なコピー・裏向き補助など、プレイ中にカード状の現物として必要になりそうなものを、探しやすい順に並べます。

## パスワード付きのWeb版

[MTG Token Finder 公開版](https://mtg-token-finder-nobinko.nobinko.chatgpt.site) をスマホ・PCのブラウザから利用できます。管理者から共有されたパスワードでログインしてください。利用者によるNode.jsのインストールやPCの常時起動は不要です。画面・静的ファイル・全API・検索ログはサーバー側で認証を確認します。ログインは7日間有効で、ログアウトするとそのセッションは失効します。検索ログはログインごとに分離し、公開データの検索キャッシュと環境データはR2、ログイン試行回数と失効セッションのハッシュはD1で管理します。

大会リスト・ひとり回し履歴・準備表のチェックは端末のブラウザーに保存します。共用端末では右上の「ログアウト」から「保存データも消してログアウト」を選んでください。同じブラウザーの保存データは個人アカウントで分離されていません。MeleeのAPI用ID・シークレットは保存せず、その取得リクエストだけで利用します。[情報の扱いと検査内容](docs/privacy-security-review-2026-10-21.md)も参照してください。

共有パスワードのSHA-256を `SITE_PASSWORD_SHA256`、独立したランダム署名キーを `SESSION_SECRET` としてSitesのシークレットに設定します。実際のパスワード・キーをソースやGitに保存しないでください。パスワードの変更で既存のログインも無効になります。公開先のIDと保存領域の論理名は `.openai/hosting.json` に記録しています。

`npm run build` で公開用Workerを生成します。D1スキーマを変更した場合は `npx drizzle-kit generate` で追加マイグレーションを生成してください。ローカル版の起動方法はこれまでどおりです。ローカルでも認証したい場合は `.env.example` を元に設定し、`node --env-file=.env server.mjs` で起動します。公開版は認証設定が欠けるとアクセスを拒否します。

公開元はGitHubの`main`です。Sitesのクラウドタスクが1時間ごとに更新を確認し、テスト・公開用ビルド・認証と保存領域の確認に通った最新版を反映します。push直後の反映ではありません。自動公開とパスワード変更の手順は [GitHub mainからの自動公開](docs/github-deployment.md) にまとめています。ログイン後の `/api/version` で公開中の元コミットを照合できます。

## すぐ使う

リポジトリのフォルダにある **`start.bat`** をダブルクリックします。

- 初回だけパッケージを自動インストールします。
- 数秒後にブラウザで `http://localhost:5177` が開きます。
- 使い終わったら黒いウィンドウを閉じます。

PowerShellで起動する場合:

```powershell
npm install
npm start
```

## 現在できること

- Standard / Pioneer / Modern / Legacy を選択
- 「大会を選ぶ」ではMeleeの最近の国内大会をカードから選び、公開デッキリストを直接取得。ログイン・ファイル準備は不要。海外・オンライン・所在地未確認は「その他」へ分け、小規模大会も人数下限なく表示。スタッフ権限で書き出した公式JSONも取り込める。API用ID・シークレットを受領した方には、本人の認証情報で取得する別の入口を用意（有効な本人認証での接続確認は未実施）。保存済み大会や受け取ったテキスト・CSVも補助の入口から使える。大会内のメイン・サイド・相棒から必要トークンと画像付きリストを表示し、未取得人数を区別
- 大会日から現環境開始日を判定し、古いデッキリストを混ぜずに巡回
- MTGO公式（対象期間の月別索引）、MTGTop8、magic.gg、晴れる屋の大会記事・個別デッキ・メタページをフォーマット別に巡回
- 「最近の環境から」の検索結果に、選択フォーマットのMTGTop8の直近集計を母数・集計期間・取得日時付きで表示。大会・環境を選ぶ前に検証用の固定10種類を提示する入口は置かない
- 上位アーキタイプごとに直近の完全リストを比較し、典型例となる実在の60+15枚リストを表示・Arena形式でコピー
- 選んだ実リストを画像付きのひとり回しへ展開。マナ支払い、対応する呪文・誘発・起動・コンボを自動処理し、対象や捨てるカード等を選択。ドラッグ移動、フェッチ、山札操作、カウンター、トークン、サイド入替、Undo/Redoも使用できる。保存したゲームはトップ画面の「ひとり回しの続き」から直接再開
- デッキ内で使われているトークン生成カードを抽出
- 各トークンの「このトークンを使うデッキ（画像付き）」から、採用している実際のリストのメイン・サイドをカード画像付きで表示。画像の拡大、日本語切替、原リストへの移動にも対応
- 環境全体検索の発生源は紙のカードかつ選択フォーマットで使用可能なものに限定。大会リストモードは提出カードを直接照合し、使用可否の判定は行わない。抜き出し先は通常セットに加え、ModernのLTR・MH1〜3・ACR等、選択フォーマットに対応する特殊セットも同じ欄に表示
- モダンでは発生源が最初にモダンに収録されたセットのトークンを優先（例：アーデンベイル城の人間はELD）。該当する版がなければ同じ仕様の別セットから補充
- 必要・未準備・準備済み・別途用意の種類数を表示。準備に使うセットだけを先に表示し、セットを押してカード準備表へ移動。全モダン年表、検索の詳細、環境・デッキ内訳は折りたたみ
- 各現物の「手元のセットから別版を探す」で、色・サイズ・タイプ・能力が一致する対象セットの版を画像付きで確認。統率者版はLegacyのみ対象。マスターズ・プロモ・特殊フレーム等は除外
- BIG→OTJなど同一商品の親セットも照合。対象セット版が見つからない必要トークンは消さず、画像を非表示にして「別途用意するもの」へ。汎用マーカーも専用の準備欄へ
- 同じ仕様の宝物・食物・手掛かり等は準備状況を共有し、「OTJで抜き出し済み」のように実際の準備元を表示。別セット版の「ここで抜いた」でも記録できる
- 同じ大会・日付・プレイヤー・メイン/サイド構成の転載デッキを重複集計しない（情報不足のリストは無理に統合しない）
- トークン、紋章、物理的なコピーに加え、ワープ・計画済み・準備済み・昼夜・裏向き（予示など）の状態を見失わないための補助物を表示。都市の承認・統治者・指輪・ダンジョン・エネルギー等も対象。[補助物の点検記録](docs/auxiliary-coverage.md) に範囲を記載。発生源と実際の採用リストまで確認可能
- 採用デッキ数、採用元、アーキタイプ傾向を表示
- 日本語名と日本語画像を後追い補完
- エキスパンション順/種類別、発売日順、未チェックのみ表示、印刷用表示
- 暗い表示（既定）と明るい表示を切り替え。準備の進み具合と表示設定を画面上部に固定し、PCでは抜き出すセット一覧を右側に固定表示
- 巡回ログをリアルタイム表示
- 検索デッキ/リスト数を20-600件の範囲で扱う

## 開発

共通のサーバー側処理は `app.mjs` と `lib/`、起動入口はローカル用の `server.mjs` と公開用の `worker.mjs`、画面側は `public/` に分かれています。詳しい責務分担は [docs/architecture.md](docs/architecture.md) を見てください。

```powershell
npm install
npm start
```

## 注意

- このツールは身内の大会準備用途の非公式Fan Contentです。Magic: The Gathering のカード画像・テキスト等は Wizards of the Coast に帰属します。このツールは Wizards of the Coast / Scryfall 非公認です。
- サイト側のHTML構造変更やアクセス制限で巡回できないページがあります。
- WAF、Cloudflare、robots.txt、明示的なアクセス制限を回避して巡回する用途ではありません。
- Scryfall照合母集団の枚数は、デッキ数に応じて変わる数字ではありません。検索デッキ数で変わるのは、ヒットした生成カード数、現物の種類数、採用デッキ数です。
- 生成物の判定はOracle、Scryfall関連カード情報、公式確認済み日本語テキストに基づきます。配信前の最終確認ではカード画像やOracleも確認してください。
- 日本語画像は取得できたものだけ切り替わります。日本語名は空にしませんが、`名称要確認` を含むものは公式トークン名の追加確認が必要です。
- トップメタ順位は検索対象デッキの自動分類ではなく、MTGTop8が現在公開している直近集計です。過去の大会日を指定しても、その当時のメタ順位にはなりません。
- ひとり回しは、自分の展開と勝ち筋を練習する範囲です。ライフ・毒・空の山札からのドロー・対応する特殊勝利を判定し、決着を表示します。相手の盤面・手札内容・ブロック・優先権はモデル化していません。未対応の能力・相互作用は手動です。[対応範囲](docs/goldfish-rules.md)と[実リストの検証範囲](docs/goldfish-top10.md)を確認できます。盤面・選択途中の状態・最大60件の操作履歴は登録デッキごとに同じブラウザへ保存され、サイド入替後も元の登録リストから再開できます。
