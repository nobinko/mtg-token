## 閲覧と再生成

ZIPは全ファイルを同じフォルダーへ展開してから開く。HTMLは同梱のCSS・JavaScript・画像・テキストリストのみを読み、閲覧時の外部API呼び出しはない。出典リンクには通信が必要。JavaScriptを無効にした場合も、本文・全リスト・コンボの全文は読める。

開発時はリポジトリーのルートから実行する。生成処理は同梱した固定データを用い、最新の環境へ自動更新するコマンドではない。

```powershell
node reports/modern-meta-2026-10-01/build.mjs
node reports/modern-meta-2026-10-01/validate.mjs
npm test
python -m http.server 5199 --bind 127.0.0.1 --directory reports/modern-meta-2026-10-01
```

`build.mjs` がHTML・ブラウザー用データ・22件のテキストリストを生成する。CSS/JavaScriptは内容に基づくバージョン付き。`validate.mjs` は75枚の一致、4枚制限、初手の実在、重要カード、合法性の保存値、画像の実ファイル、相性の逆方向、索引・アンカー・生成データを検証する。**検査の成功だけで外部データの完全性や解説の無誤謬は証明しない。**

`source-reader.mjs` は資料取得専用のアダプター。HTTP charsetを尊重し、相棒の装飾用の入れ子だけを取り除いてから既存のデッキ抽出器を使う。通常アプリの実装と利用者キャッシュは変更していない。

取得根拠・入力ハッシュは [provenance.json](provenance.json)、実施済みの確認と確認外の範囲は [verification.json](verification.json) を参照。一次取得のHTML、作業用スクリプト、プレビュー画像、配布ZIPはGit対象から除外する。
